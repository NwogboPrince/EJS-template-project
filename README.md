# 4.0 EJS Project 

This is a simple Node.js project using **Express**, **EJS**, and **Body-Parser** to demonstrate rendering templates and handling form submissions.

## Features
- Renders an EJS template (`index.ejs`) for the homepage.
- Accepts form submissions via POST requests.
- Calculates the total number of letters in the first name and last name submitted through the form.

## Prerequisites
- Node.js installed on your machine.
- A package manager like `npm` or `yarn`.
